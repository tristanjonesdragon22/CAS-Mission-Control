On your iPad, use the Windows computer's private-network IP address, not 127.0.0.1. Keep the bridge on trusted Wi-Fi only. A connection is required for original CAS analysis and general symbolic operations outside the offline polynomial subset.

Compatibility

Offline numeric expressions and supported polynomial operations run in the independent JavaScript engine. Offline polynomial factoring is limited to degree 2; solving quadratic equations includes complex roots. For definite integrals enter lower,upper:polynomial (example: 0,2:x^2). Polynomial integration is now available offline (including a constant of integration). More general symbolic integration requires the Python backend with SymPy installed. Original CAS analysis uses the selected original MathEngine, not the entire historical Windows platform.
